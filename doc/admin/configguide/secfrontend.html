Front-End Encryption and Secure Authentication

When configured to use the SQLRClient protocol (the default), SQL Relay supports Kerberos and Active Directory Encryption and Authentication and TLS/SSL Encryption and Authentication between the client and SQL Relay server.


When configured to use the MySQL protocol, SQL Relay supports TLS/SSL Encryption and Authentication between the client and SQL Relay server.


When configured to use the PostgreSQL protocol, SQL Relay supports TLS/SSL Encryption and Authentication between the client and SQL Relay server.


When configured to use the Firebird protocol, SQL Relay supports Firebird Wire Encryption between the client and SQL Relay server.


When configured to use the TDS protocol, SQL Relay supports TLS/SSL Encryption and Authentication between the client and SQL Relay server.
