Firebird Protocol

SQL Relay can be configured to speak the native Firebird protocol, enabling client programs for Firebird (eg. the isql command line program) to access SQL Relay directly.

If an instance speaks the Firebird client-server protocol, then any client that wishes to use it must also speak the Firebird client-server protocol. This means that most software written using the Firebird API (fbclient), or written using a database abstraction layer which loads a driver for Firebird, such as the Jaybird JDBC driver or the Firebird ODBC driver, can access this instance. However, it also means that SQL Relay's standard sqlrsh client program and client programs for other databases (eg. the mysql, psql, and sqlplus command line programs, MySQL Workbench, SQL Server Management Studio, etc.) cannot access this instance.
