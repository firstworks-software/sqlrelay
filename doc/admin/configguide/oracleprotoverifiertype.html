Password Verifier Type

The verifiertype option sets which kind of password verifier the Oracle protocol module tells clients it uses: 9i, 11g or 12c. If unset, it follows serverversion (see Server Version): 12c for 12.1, and 11g for 11.2. Any other value is the same as leaving it out.

<?xml version="1.0"?>
<instances>
	<instance id="example" dbase="oracle">
		<listeners>
			<listener protocol="oracle" port="1521" verifiertype="11g"/>
		</listeners>
		<connections>
			<connection string="user=scott;password=tiger;oracle_home=/u01/app/oracle/product/12.1.0;oracle_sid=ora1"/>
		</connections>
	</instance>
</instances>

Clients older than Oracle 10g, such as OCI7 apps, can only log in with 9i, and modern clients can't log in with it. 9i also makes the module report Oracle 10.2, whatever serverversion says. It is much less secure than the others, so only use it for clients that need it. A 9i listener can share an instance, and its back-end database, with a modern one. Just give it its own port, as shown below.

<?xml version="1.0"?>
<instances>
	<instance id="example" dbase="oracle">
		<listeners>
			<listener protocol="oracle" port="1521"/>
			<listener protocol="oracle" port="1522" verifiertype="9i"/>
		</listeners>
		<connections>
			<connection string="user=scott;password=tiger;oracle_home=/u01/app/oracle/product/12.1.0;oracle_sid=ora1"/>
		</connections>
	</instance>
</instances>
