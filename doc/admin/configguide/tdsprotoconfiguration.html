Basic Configuration

To enable SQL Relay to speak the TDS protocol, add the appropriate listener tag:

<?xml version="1.0"?>
<instances>
	<instance id="example" dbase="odbc">
		<listeners>
			<listener protocol="tds" port="1433"/>
		</listeners>
		<connections>
			<connection string="dsn=mssqlodbc;user=example;password=example;mars=yes"/>
		</connections>
	</instance>
</instances>

In this configuration:

  • The listener tag instructs SQL Relay to load the tds protocol module, and listen on port 1433, which is the standard Microsoft SQL Server port.
  • The connection tag instructs the instance to log in to the mssqlodbc ODBC data source as user example with password example.

Note the mars=yes parameter in the connect string. See the SQL Relay Configuration Reference for the mars option, which instances using the tds protocol typically need.

The instance can be started using:

sqlr-start -id example

and accessed from the local machine using:

tsql -H localhost -p 1433 -U example -P example

The instance can be stopped using:

sqlr-stop -id example
