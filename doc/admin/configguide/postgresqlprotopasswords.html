Password Method

By default, the PostgreSQL protocol module challenges a connecting client for an md5 hash of its password rather than the password itself. Setting the passwords attribute on the listener tag to "cleartext" makes the module accept the password itself instead.

<?xml version="1.0"?>
<instances>
	<instance id="example" dbase="postgresql">
		<listeners>
			<listener protocol="postgresql" port="5433" passwords="cleartext"/>
		</listeners>
		<connections>
			<connection string="user=postgresqluser;password=postgresqlpassword;db=postgresqldb;host=postgresqlhost"/>
		</connections>
	</instance>
</instances>

Cleartext passwords are required when a one-way password encryption module is used for a database user's password - see Password Encryption for why - and sends the password over the network as typed, so it should only be used with TLS or on a trusted network.
